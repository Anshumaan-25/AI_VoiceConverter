# AI Voice Converter (so-vits-svc)

This workspace is now wired for your chosen path:

- Inference first
- Then custom training
- Gradio interface for v1
- NVIDIA CUDA target

## What Was Implemented

- `so-vits-svc/` cloned from upstream (your previous `so-vits` zip only contained an empty `logs/44k` folder).
- `so-vits-dataset/` extracted and available.
- `voice_autopilot.py` added to orchestrate dataset prep, preprocess, training, and one-shot inference.
- `gradio_app.py` added as a simple conversion UI.
- `setup_autopilot.ps1` added to create/install a CUDA-ready virtual environment.

## Project Layout

- `so-vits-svc/` core framework
- `so-vits-dataset/raw/` your source audio samples
- `voice_autopilot.py` command-line autopilot wrapper
- `gradio_app.py` local web app
- `setup_autopilot.ps1` environment bootstrap script

## Quick Start

## 1. Environment Setup

Run from workspace root:

```powershell
./setup_autopilot.ps1
```

Activate environment:

```powershell
./.venv310/Scripts/Activate.ps1
```

Verify runtime:

```powershell
python voice_autopilot.py check
```

## 2. Prepare Dataset

Place your target speaker clips in a folder (you currently have samples in `so-vits-dataset/raw`).

Convert and copy into `so-vits-svc/dataset_raw/<speaker>`:

```powershell
python voice_autopilot.py prepare-data --source so-vits-dataset/raw --speaker anshu --clean-target
```

This enforces WAV mono 44.1kHz, which matches so-vits defaults.

## 3. Preprocess

```powershell
python voice_autopilot.py preprocess --speech-encoder vec768l12 --f0-predictor rmvpe --skip-loudnorm
```

## 4. Train

```powershell
python voice_autopilot.py train --model-name 44k
```

The wrapper sets `USE_LIBUV=0` automatically to avoid a known Windows + Torch distributed initialization issue.

Training outputs are stored in:

- `so-vits-svc/logs/44k/`

## 5. Test Inference (CLI)

```powershell
python voice_autopilot.py infer \
  --input so-vits-dataset/raw/Anshumaan_voice_sample.wav \
  --model so-vits-svc/logs/44k/G_*.pth \
  --config so-vits-svc/configs/config.json \
  --speaker anshu \
  --transpose 0
```

Note: replace `G_*.pth` with an actual checkpoint path (for example `G_12000.pth`).

## 6. Launch Gradio UI

```powershell
python gradio_app.py
```

Then open:

- `http://127.0.0.1:7860`

## Success Criteria for v1

The implementation targets your definition:

- intelligible speech,
- perceptible target-speaker similarity,
- minimal distortion.

## Important Notes

- so-vits-svc requires additional pretrained assets (`pretrain` weights such as content encoder / rmvpe). Follow upstream README in `so-vits-svc/README.md` to download them before training/inference.
- You can bootstrap required core pretrained files automatically with:

```powershell
./download_pretrain.ps1
```

- `setup_autopilot.ps1` intentionally pins `pip<24.1` and `setuptools<81` for fairseq/librosa compatibility.
- With very small datasets, autogenerated `train.txt` can be empty; `voice_autopilot.py preprocess` now auto-rebalances one sample into train when possible.
- Use only authorized voice data with explicit consent.
- The old notebook (`Untitled0.ipynb`) is unrelated to this pipeline and can be archived.
